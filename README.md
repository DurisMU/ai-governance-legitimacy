# Algorithmic Explanations and Institutional Legitimacy in AI-Enabled Governance

A reproducible analysis of a 2 (decision stakes) x 3 (explanation type)
between-subjects experiment (N = 420) examining how algorithmic explanations
shape citizens' perceptions of institutional legitimacy, trust, and policy
acceptance in AI-enabled public governance.

## Repository structure

```
.
```

## Data

`data/raw_data.xlsx` is the unmodified export from the survey platform. It is
stored in a wide format with two header rows: each of the six experimental
conditions has its own block of item columns, and each participant answered
only the block matching their randomly assigned condition. `code/clean.py`
transforms this into `data/cleaned_data.csv`, a tidy dataset with one row per
participant.

`data/cleaned_data.csv` contains 420 rows and 31 columns. Rows are anonymous
survey respondents; the first two columns encode the experimental conditions
(`Stakes_Group` x `Explanation_Group`), followed by item-level and composite
scores for the three outcome measures and four control measures, plus
demographic variables. See `data_dictionary.md` for full variable definitions.
All composite scores are unweighted item means.

## Reproducing the analysis

### 1. Install dependencies

Python 3.9+ with:

```bash
python3 -m pip install pandas numpy scipy statsmodels matplotlib seaborn openpyxl tabulate
```

To render the PDF report, also install [Quarto](https://quarto.org) and a LaTeX
engine (TinyTeX recommended):

```bash
quarto install tinytex
```

### 2. Clean the raw data

```bash
python3 code/clean.py
```

This reads `data/raw_data.xlsx` and writes `data/cleaned_data.csv`.

### 3. Run the analysis

```bash
python3 code/analysis.py
```

This prints reliability statistics, descriptive statistics, ANOVA tables,
simple effects, and post-hoc tests, and writes figures to `figures/` and result
CSVs to `data/`.

### 4. Render the report

```bash
cd report && quarto render report.qmd
```

The report is written to `report/report.pdf`.

## Analysis summary

Three outcome scales (perceived institutional legitimacy, institutional trust,
policy acceptance) showed good internal consistency (Cronbach's α = .92, .88,
.92). 2 x 3 ANOVAs revealed large main effects of decision stakes on all
outcomes (partial η² = .17–.27) and smaller main effects of explanation type
(partial η² ≈ .04), qualified by a significant stakes x explanation interaction
for every outcome (partial η² ≈ .03). Simple-effects tests showed explanation
type had no effect under low stakes, but under high stakes empathic
explanations produced the lowest legitimacy (M = 2.48) relative to outcome
(M = 3.11) and process (M = 3.25) explanations.
